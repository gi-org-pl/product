# Generacja Innowacja

> The roadmap, decisions and documentation that concern the whole foundation, not a single product.

## Contents
| Folder | Description |
|---|---|
| [docs](./docs/README.md) | Roadmap, initiatives and decisions of the foundation |

What belongs here is whatever applies to the foundation as a whole: how it runs, what it keeps safe, what it decides for every project. What belongs to one product stays in that product's folder, for example [myPolitics](../mypolitics/README.md) - its specs, epics and developer tasks are not repeated here.

Files are shaped as described in the [myPolitics conventions](../mypolitics/conventions/README.md); there is no separate set for this folder. This folder is not part of the published site yet.
