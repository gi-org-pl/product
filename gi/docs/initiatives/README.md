# Initiatives

> Organisation-wide initiatives - work that serves the whole foundation and belongs to no single product.

An initiative is a file shaped like an idea in the [idea template](../../../mypolitics/conventions/idea-template.md): context, opportunity, risk and a decision. It is written when the initiative is proposed and kept up to date as it moves. An initiative that is agreed is put on the [roadmap](../roadmap/README.md).
