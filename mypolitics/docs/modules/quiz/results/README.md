## Context
The result is what the whole product is for. It arrives in a fixed order: a [loader](./engaging-loader.md) that spends the wait, a [short card](./short-results-card.md) that summarises everything and can be saved as an image, then the full screen.

The full screen is:

- **A [header](./modules/header.md)** - one orientation, named, with how confident we are about it.
- **Two tabs** - the taker's own result, and [comparison](./comparison/README.md).
- **A set of [modules](./modules/README.md)** - each a frame around the same bar, each pointed at orientations the quiz author chose.
- **A [next quiz](./follow-up-recommendation.md)** - offered where the reading finishes.

Depth stays one tap away rather than on the page: every module can open its [explanation](./info-modals.md) and its [statistics](./module-statistics.md), which is what keeps the default screen a result instead of a dashboard.
