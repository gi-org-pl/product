## Context
The second tab of the result screen. A taker compares either with a friend, by exchanging result identifiers, or with an orientation the quiz scores.

What each mode gives:

- **Friend** - the full [results comparison](./results-comparision.md) across every module, and the [answers comparison](./answers-comparision.md).
- **Orientation** - [answers comparison](./answers-comparision.md) only, because an orientation has no result of its own to overlay.

Both modes keep the [agreement score](./agreement-info.md) on screen for as long as the comparison lasts, and neither draws anything new: comparison is an overlay the [universal axis](../modules/universal-axis.md) already carries.
