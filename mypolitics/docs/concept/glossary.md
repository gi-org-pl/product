# Glossary

> Definitions of terms used in the myPolitics project. 

## Terms
| Term | Definition |
|---|---|
| Orientation | A named position a quiz can score - the unit an answer supports or opposes. |
| Checkpoint | A partial result shown mid-quiz, before the final one. |
| Para-poll | A rotating question set appended to the end of a quiz to collect survey data. |
